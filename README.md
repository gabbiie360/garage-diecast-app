# Garage Diecast — app de Android

Instalador de la app de Android de Garage Diecast para el equipo.

**[Descargar la última versión](https://github.com/gabbiie360/garage-diecast-app/releases/latest)**: abrí el enlace y tocá el archivo `GarageDiecast-<versión>.apk`.

Todas las versiones están en [Releases](https://github.com/gabbiie360/garage-diecast-app/releases).
Este repositorio solo guarda el instalador: el código de la app es privado.
